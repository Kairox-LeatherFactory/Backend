The six blockers all tagged D0

  1. 1

    Piece-rate payroll cannot run at all

    production/repository.py:213,222 — the wage aggregate groups and orders by Piece.style_id, a column that does not exist. Every run raises AttributeError before emitting SQL. Reproduced in tests/test_wages.py.

  2. 2

    A payroll run 500s after committing and closing

    wages/service.py:572 calls employees.names_for, which does not exist, whenever a MONTHLY employee has a null salary — after add_lines and close_run have already committed. The cleanup handler then fails on the FK.

  3. 3

    The repository is in an unresolved merge

    git ls-files -u shows three index stages for imports/load_to_db.py and add/add for production/router.py. What was tested is the working tree; what would be committed is undefined.

  4. 4

    The barcode attendance door is 100% broken

    attendance/router.py:64 reads body.direction; the field is not on ScanCheckIn. Every scan check-in 500s — this is how the floor punches in.

  5. 5

    Any client login can check in any employee

    attendance/router.py:59 guards only the proxy=true case. With proxy=false a CLIENT or VIEWER token writes attendance for anyone — and attendance gates all production logging. Masked today by blocker 4.

  6. 6

    Three production GETs 500 on every call

    production/router.py:71,98,110 pass a client_scope kwarg the service signatures do not accept. They are also untenanted once the TypeError is fixed — fix the signature, not the call site.
